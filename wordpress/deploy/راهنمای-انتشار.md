# انتشار سایت نیکابنا

سایت: https://www.nikabana.ir/
پیشخوان وردپرس: https://www.nikabana.ir/wp-admin/

## روش کار روزمره

1. تغییرات قالب و افزونه را در شاخه `wordpress` انجام دهید.
2. Commit و Push کنید. شاخه `main` نسخه اولیه Next.js است و برای هاست وردپرس منتشر نمی‌شود.
3. هاست هر پنج دقیقه گیت‌هاب را بررسی می‌کند و نسخه جدید را منتشر می‌کند؛ زمان کپی فایل‌ها هم به این فاصله اضافه می‌شود.
4. تغییر متن، پروژه، عکس، کاربر یا رویداد تایم‌لاین را از داخل وردپرس یا پنل سایت انجام دهید. این اطلاعات در گیت‌هاب ذخیره نمی‌شوند و انتشار کد آن‌ها را تغییر نمی‌دهد.

فقط پوشه‌های `wordpress/themes/mojarrad` و `wordpress/plugins/mojarrad-core` منتشر می‌شوند. فایل تنظیمات وردپرس، دیتابیس، رسانه‌ها و مخزن فایل‌های خصوصی در این کار تغییر نمی‌کنند. فایل‌ها را مستقیم در این دو پوشه روی هاست ویرایش نکنید؛ در گیت‌هاب ثبتشان کنید.

## بازگشت به یک تغییر قبلی

از Revert و یک Commit جدید در شاخه wordpress استفاده کنید. انتشار، تاریخچه قدیمی یا Force Push را قبول نمی‌کند تا سایت ناخواسته به نسخه‌های گذشته برنگردد.

## انتشار دستی و بررسی خطا

در cPanel بخش Git Version Control، مخزن Nikabana WordPress، گزینه Manage و سپس Pull or Deploy را باز کنید. Update from Remote و بعد Deploy HEAD Commit انتشار دستی را انجام می‌دهند.

گزارش زمان‌بندی در فایل خصوصی `/home/tutivari/nikabana-deploy.log` است. زمان‌بندی در Cron Jobs قرار دارد. هیچ رمز یا توکن گیت‌هاب برای این اتصال ذخیره نشده؛ مخزن در حال حاضر از طریق HTTPS بدون ورود روی هاست قابل دریافت است. اگر مخزن خصوصی شود، باید روش دسترسی جداگانه تنظیم شود.
