# تصاویر عمومی پروژه‌ها

برای هر پروژه یک پوشه به نام شناسه ثابت آن بسازید، مانند `media/nb-0001/`. تصویر شاخص می‌تواند `cover.webp` و تصویرهای گالری `01.webp`، `02.webp` و غیره باشند. مسیر در پرونده پروژه از همین پوشه `content/projects` شروع می‌شود؛ مثال: `media/nb-0001/cover.webp`.

فقط تصاویر با حق انتشار عمومی و کیفیت وب ذخیره شوند. عکس‌های اصلی بسیار حجیم، مدارک محرمانه و نسخه‌های دارای اطلاعات شخصی در مخزن عمومی قرار نگیرند. برای هر تصویر در JSON، متن جایگزین `alt` و وضعیت مجوز انتشار ثبت شود.
