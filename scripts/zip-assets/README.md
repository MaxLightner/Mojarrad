# وب‌سایت گروه ساختمانی نیکا بنا

وب‌سایت رسمی و پنل پروژه‌های **گروه ساختمانی نیکا بنا** — مهندس حسین مجرد، مشهد
ساخته‌شده با Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite)

---

## ۱. امکانات کلیدی

| بخش | توضیح |
|---|---|
| **سایت عمومی** | صفحه اصلی با انیمیشن شکل‌گیری ساختمان، پورتفولیوی پروژه‌ها (در دست اقدام / انجام‌شده / آینده)، اخبار با بنر مناسبتیِ عکس‌دارِ چرخان، وبلاگ، معرفی مسئولین، دفترچه تلفن مجریان، وضعیت پیمانکاری، تماس با ما |
| **۴ تم رنگی** | روشن، تیره، پاستلی و سورمه‌ای-نارنجی — انتخاب کاربر در localStorage ذخیره می‌شود |
| **پنل من** (داشبورد نقش‌محور) | مدیر سایت: همه پروژه‌های فعال + ساخت پروژه جدید + ساخت کاربر و تخصیص مالک/ناظر. مالک/ناظر/مجری/پیمانکار: فقط پروژه‌های خودشان + فید به‌روزرسانی‌ها |
| **تایم‌لاین پروژه** | روایت دکوراتیو اجرای پروژه: ستون فقرات + گره‌ها با مورف پیوسته، نخ‌های رنگی مراحل، اسکرول سینمایی آهسته، کامنت‌گذاری، عکس و فایل |
| **آرشیو ZIP** | با پایان پروژه، مدیر با یک کلیک کل سوابق (رویدادها، پیام‌ها، پرداخت‌ها، اسناد، عکس‌ها) را به‌صورت فایل ZIP دریافت و پروژه را از داشبورد می‌بندد |
| **پنل مدیریت محتوا** | ویرایش اخبار، مناسبت‌ها و وبلاگ + ساخت پروژه و کاربر — بدون نیاز به کدنویسی |
| **فارسی کامل** | راست‌به‌چپ (RTL)، تاریخ شمسی، فونت وزیرمتن |

## ۲. پیش‌نیازها

- **Node.js نسخه ۲۰ یا بالاتر** (پیشنهاد: ۲۰ LTS یا ۲۲) — از [nodejs.org](https://nodejs.org) دانلود کنید

```bash
node -v

```

## ۳. راه‌اندازی سریع (سه دستور)

پوشه را باز کنید و در ترمینال (داخل همین پوشه) اجرا کنید:

```bash
npm install
npx prisma generate
npm run dev
```

سپس در مرورگر باز کنید: **http://localhost:3000**

> دیتابیس دمو (فایل `db/custom.db`) همراه بسته است؛ یعنی سایت بلافاصله با ۸ پروژه، اخبار، وبلاگ و کاربران دمو بالا می‌آید. اگر خواستید همه‌چیز را از صفر بسازید: `npm run db:push` و بعد `npm run db:seed`

## ۵. ساخت نسخه پروداکشن

```bash
npm run build
npm start
```

> **نکته ویندوز:** دستور `npm run build` در پایان دو دستور `cp` دارد که مخصوص لینوکس/مک است. در ویندوز یا از WSL استفاده کنید یا بعد از بیلد، پوشه‌های `.next/static` و `public` را دستی داخل `.next/standalone` کپی کنید.

> **نکته مهم دیتابیس در پروداکشن:** مسیر SQLite در `.env` به‌صورت نسبی است و برای `npm run dev` کافی است. هنگام اجرای پروداکشن روی سرور، مسیر را **مطلق** کنید تا مشکلی پیش نیاید:
> ```
> DATABASE_URL=file:/home/USER/nika-bona/db/custom.db
> ```
> (مسیر واقعی سرور خودتان را جایگزین کنید — در ویندوز مثلاً `file:C:/nika-bona/db/custom.db`)

## ۶. روی چه هاستی منتشر کنم؟ (پاسخ سؤالات رایج دیپلوی)

این سایت «فول‌استک» است؛ یعنی هم صفحه نمایش می‌دهد و هم بک‌اند (API + دیتابیس) دارد. پس به هاستی نیاز دارید که **Node.js را اجرا کند**. هاست‌های معمول PHP (مثل سی‌پنل قدیمی) جواب نمی‌دهند.

### گزینه ۱ — سرور مجازی (VPS) — بهترین برای این پروژه ✅
یک VPS لینوکسی ساده (حداقل ۲ گیگ رم) از هر شرکت ایرانی یا خارجی بگیرید (در ایران معمولاً ماهی چند صد هزار تومان). سپس:

```bash
# نصب Node.js و PM2 و Nginx روی اوبونتو
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm i -g pm2

# اجرای سایت (پوشه پروژه را با Filezilla یا git روی سرور ببرید)
cd /var/www/nika-bona
npm install && npx prisma generate
npm run build
pm2 start npm --name nika-bona -- start
pm2 startup && pm2 save
```

بعد در Nginx یک سرور بلاک به پورت ۳۰۰۰ بسازید و SSL رایگان بگیرید:

```nginx
server {
    server_name nikabona.ir;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo certbot --nginx -d nikabona.ir   # SSL رایگان
```

### گزینه ۲ — پلتفرم‌های ابری ایرانی (لیارا / ابرآروان / پادیش)
- در **لیارا** یک «اپ Node.js» بسازید، همین پوشه را آپلود یا با گیت وصل کنید؛ دیتابیس SQLite آنجا هم پشتیبانی می‌شود (ولی حتماً «دیسک دائمی» به اپ وصل کنید تا فایل دیتابیس با هر بار دیپلوی پاک نشود). برای محصولات جدی‌تر می‌توانید دیتابیس لیارا (Postgres) بگیرید — فقط کافی است در `prisma/schema.prisma` مقدار `provider` را از `sqlite` به `postgresql` تغییر دهید و دوباره `db:push` بزنید.
- نحوه کار: ریپازیتوری گیت بسازید → پوش کنید → لیارا خودش `npm install` و `npm run build` را اجرا می‌کند.

### گزینه ۳ — Vercel (ساخته‌کننده خود Next.js) — خارج از ایران
- رایگان و ساده است؛ ریپوی گیت‌هاب را به [vercel.com](https://vercel.com) وصل می‌کنید و تمام.
- **محدودیت مهم:** دیتابیس فایل SQLite روی Vercel ماندگار نیست؛ باید دیتابیس ابری رایگان بگیرید (مثل Neon یا Turso) و `DATABASE_URL` را در تنظیمات Vercel بگذارید.

### گیت‌هاب؟
بله، توصیه می‌شود: یک ریپوزیتوری خصوصی بسازید، این پوشه را پوش کنید و از آن به‌عنوان نسخه اصلی کد استفاده کنید. پوشه‌های `node_modules` و `.next` و `db` به‌طور خودکار نادیده گرفته می‌شوند (در `.gitignore` تنظیم شده).

## ۷. پنل مدیریت محتوا (ویرایش بدون کدنویسی)

پنل کنترل داخلی سایت از قبل ساخته شده و نیازی به CMS جداگانه ندارد:

1. با کاربر `admin` وارد شوید
2. در «پنل من» → **ابزارهای من** → **مدیریت** را باز کنید
3. از آنجا می‌توانید:
   - **اخبار و مناسبت‌ها** را اضافه/ویرایش/حذف کنید (عکس بنر هم آپلود می‌شود)
   - **مطالب وبلاگ** را مدیریت کنید
   - **پروژه جدید** بسازید و در همان لحظه مالک و ناظر به آن تخصیص دهید
   - **کاربر جدید** با هر نقش بسازید

متن‌های ثابت صفحات (معرفی، مسئولین و…) داخل کد در `src/components` و `src/app` است؛ برای تغییر آنها ویرایش ساده متن کافی است و نیازی به برنامه‌نویسی ندارد.

## ۸. ساختار پوشه‌ها

```
nika-bona/
├── prisma/               # مدل‌های دیتابیس + فایل سیدِ داده دمو
│   ├── schema.prisma     # ساختار جداول (کاربر، پروژه، رویداد، خبر و…)
│   └── seed.ts           # داده‌های نمونه اولیه
├── db/
│   └── custom.db         # دیتابیس SQLite (همراه داده دمو)
├── public/
│   ├── fonts/            # فونت وزیرمتن
│   ├── images/           # عکس پروژه‌ها + بنرهای مناسبتی
│   └── uploads/          # فایل‌های آپلودی کاربران
├── src/
│   ├── app/              # صفحات و APIهای سایت (Next.js App Router)
│   ├── components/       # کامپوننت‌های UI (تایم‌لاین، داشبورد، اخبار و…)
│   └── lib/              # ابزارهای مشترک (اتصال دیتابیس، تاریخ شمسی و…)
├── .env                  # آدرس دیتابیس
├── package.json          # دستورات و وابستگی‌ها
└── next.config.ts
```

دستورات پرکاربرد:

| دستور | کار |
|---|---|
| `npm run dev` | اجرای محیط توسعه روی پورت ۳۰۰۰ |
| `npm run build` | ساخت نسخه پروداکشن |
| `npm start` | اجرای نسخه پروداکشن |
| `npx prisma studio` | محیط گرافیکی دیدن/ویرایش دیتابیس |
| `npm run db:seed` | بازنشانی داده‌های نمونه (همه داده‌ها پاک و از نو ساخته می‌شوند!) |

## ۹. نکات نگهداری

- **پشتیبان‌گیری:** کل داده‌ها در فایل `db/custom.db` است؛ به‌طور منظم از همین فایل کپی بگیرید (حتی بدون خاموش‌کردن سایت هم قابل کپی است، ولی مطمئن‌تر آن است که هنگام کپی، کاربری در حال ثبت اطلاعات نباشد). فایل‌های آپلودی در `public/uploads` هستند.
- **تغییر رمز مدیر:** با ورود `admin`، از منوی کاربری رمز را عوض کنید.
- **آرشیو پروژه:** وقتی پروژه‌ای تمام شد، مدیر از داشبورد دکمه «آرشیو» را می‌زند؛ ZIP کامل سوابق در «بخش آرشیو» قابل دانلود می‌ماند و پروژه از داشبورد فعال‌ها حذف می‌شود (پروژه‌های تمام‌شده همچنان در بخش عمومی پورتفولیو دیده می‌شوند).
- **خطای احتمالی Prisma بعد از تغییر schema:** `npx prisma generate` را دوباره اجرا کنید.
